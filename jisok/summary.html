차시별 요약 정리

핵심 개념 · 자주 나오는 오개념 · 출제 포인트

단원 관통 논지 — 과학적 탐구 방법으로 문제를 해결해 온 인류가, 그 과학기술이 만든 문제를 다시 과학기술과 실천으로 해결하려 한다. 마무리 서술형은 이 논지를 사례와 함께 진술할 수 있는지를 봅니다.

1차시 · 문제 인식과 가설 설정
성취기준
[9과01-01] · 교과서 10~13쪽
탐구 과정
문제 인식 → 가설 설정 → 탐구 설계 및 수행 → 결과 해석 → 결론 도출
핵심 용어
  • 문제 인식 — 관찰에서 생긴 의문을 탐구 문제로 분명히 나타내는 것
  • 가설 — 문제를 해결하기 위해 내리는 잠정적인 결론
  • 옳은 가설의 조건 — ① 간결할 것 ② 탐구로 옳고 그름을 확인할 수 있을 것 ③ 알아보려는 내용이 분명히 드러날 것
교과서 사례
‘맛있는 음료수일수록…’ → 주관적이라 검증 불가 / ‘얼음이 녹는 정도가…’ → 객관적 측정이 어려움 → “음료수의 종류에 따라 얼음이 녹는 데 걸리는 시간이 다를 것이다.”
오개념
  • “가설은 맞아야 한다” → 가설은 검증 대상. 반증되어도 의미 있는 결론이 나온다.
  • “가설 = 예상·느낌” → 측정 가능한 변인 관계로 진술해야 한다.
  • “에이크만식 절차가 과학의 유일한 방법” → 연역적 탐구는 여러 방법 중 하나이며 귀납적 탐구도 있다.
출제 포인트
주관적 표현을 측정 가능한 표현으로 바꾸기, 부적합 가설 판별 근거 서술
2차시 · 탐구 설계에서 결론 도출까지
성취기준
[9과01-01] · 교과서 13~16쪽
변인
  • 독립변인 = 조작변인 + 통제변인
  • 조작변인 — 의도적으로 변화시키는 변인 (예: 음료수의 종류)
  • 통제변인 — 일정하게 유지하는 나머지 (음료수의 양·초기 온도, 얼음의 모양·크기·개수, 비커의 크기)
  • 종속변인 — 영향을 받아 값이 변하는 변인 = 측정값 (얼음이 모두 녹는 데 걸린 시간)
탐구 순서
① 같은 양의 음료수 네 가지 준비 → ② 온도가 모두 같아질 때까지 대기 → ③ 크기·모양이 같은 얼음 다섯 개씩 → ④ 모두 녹는 데 걸린 시간 측정·기록
결과·결론
결과 해석 = 표·그래프로 의미 찾기 / 결론 도출 = 가설의 옳고 그름 판단. 가설이 옳지 않으면 수정하거나 다시 설계한다.
오개념
  • 조작변인을 두 가지 이상 동시에 바꿈 → 원인 판단 불가
  • “준비물이 같으면 변인 통제 완료” → 초기 온도·개수까지 통제 대상
  • “가설과 결과가 다르면 실험 실패” → 실패가 아니라 결론이며 재설계의 출발점
  • 결과를 가설에 맞춰 고쳐 쓰기 → 연구 윤리 위반
안전·오차
상온 조건으로 충분(뜨거운 물 금지), 플라스틱 비커 권장. 오차 요인 — 실내 온도 불균일, 얼음의 표면적 차이, ‘모두 녹은 시점’ 판단의 주관성(기준 사전 합의)
3차시 · 탐구 계획서 작성하기
성취기준
[9과01-01] · 교과서 17쪽 · 모둠 활동
필수 요소
  • 문제 인식(질문 형태) · 가설(‘만약 ~하면 ~할 것이다’)
  • 변인 통제 — 조작변인 1개 / 종속변인 / 통제변인 3개 이상
  • 준비물(측정 도구 포함) · 탐구 순서(재현 가능하게) · 주의할 점(안전) · 수행 기간
예시 주제
교실 환기 방법(모두 닫음 / 한쪽만 개방 / 양쪽 개방)에 따른 미세먼지 농도 변화 — 조작변인: 환기 방법 / 종속변인: 미세먼지 농도 / 통제변인: 교실 조건·측정 시각·측정 기기
지도 유의점
발견한 문제가 과학적 탐구로 해결 가능한지 먼저 토의하게 한다(취향·가치 판단 배제). 학생이 실제로 측정 가능한 도구와 범위인지 교사가 점검한다.
평가 요소
변인 통제의 타당성, 순서의 재현 가능성, 동료 의견을 실제로 반영해 수정했는지. “무엇을 어떻게 고쳤는가”라는 변화의 근거를 남기게 한다.
4차시 · 과학의 발전이 인류 문명에 미친 영향
성취기준
[9과01-02] · 교과서 18~20쪽
핵심 구조
자연 현상 관찰 → 과학적 원리 발견 → 기기 발명 → 기술 발달 → 문명·문화 변화
교과서 사례: 전자기 유도 → 전화기 → 스마트폰
연표
약 170만 년 전 불의 사용 · B.C. 12세기 철기 · 9세기 화약 · 13세기 금속 활자 · 17세기 만유인력 법칙(뉴턴) · 18세기 증기 기관 · 19세기 진화론(다윈) · 현재 인공지능·빅데이터
문명의 변화
농업(드론 정밀 농업) · 교통(고속 열차) · 의료(예방 접종) · 문화·예술(미디어 아트)
구분
기술 — 과학 이론을 생활에 유용하게 가공하는 수단 / 공학 — 과학 원리를 창의적으로 응용하는 학문
예) 위치 에너지 → 전기 에너지 변환은 기술, 이를 수력 발전에 응용하는 것은 공학
오개념
  • 과학 = 기술 = 공학 혼동
  • “과학의 발전은 항상 긍정적” → 6~7차시 환경 문제와 연결될 복선. 이 차시에서 단정하지 않는다.
  • “과학은 문화·예술과 무관” → 미디어 아트로 반증
5차시 · 첨단 과학기술의 활용과 미래 생활
성취기준
[9과01-02] · 교과서 21~23쪽
핵심 용어
  • 인공지능 — 사고·학습 등 기계가 사람처럼 지능을 가지는 것
  • 로봇 — 사람을 돕거나 사람이 하기 어려운 일을 대신하는 기계
  • 사물 인터넷 — 주변 사물을 인터넷에 연결해 정보를 주고받는 것
자율 주행
다양한 센서 + GPS 위치 정보 + 도로 정보 → 주행 상황 판단 → 스스로 제어. 융합 분야: 주행 기술·로봇 공학·인공지능 + 증강 현실 + 예술(내부 디자인)
남은 문제
① 보안·해킹 ② 윤리적 판단(트롤리 딜레마) ③ 법률·제도 미비 ④ 기술적 오류 대비 점검 체계
오개념
  • “자율 주행 = 사고 제로” → 센서 인식 한계와 윤리·법 문제가 남아 있다.
  • “인공지능이 모든 직업을 대체” → 지도서는 상호보완적 협력으로 서술한다.
  • 생성형 AI 조사 결과를 검증 없이 사용 → 출처 확인 습관을 함께 지도
평가 요소
적용 기술의 원리를 조사했는가 / 과학 외 어떤 분야가 융합되었는지 이해했는가 / 혜택을 설명할 수 있는가 / 문제 해결 방안이 독창적인가
6차시 · 지속가능한 삶과 에너지·환경 문제
성취기준
[9과01-03] · 교과서 24~25쪽
핵심 용어
  • 지속가능한 삶 — 미래 세대의 필요 충족 능력을 저해하지 않으면서 현재 세대의 필요를 충족시키는 삶
  • 공유지의 비극 — 개방된 자원에 개인의 이익이 앞설 때 일어나는 자원 고갈
  • 지속가능성 — 1987년 브룬틀랜드 보고서의 정의
  • 과학 관련 사회적 쟁점(SSI) — 기후 변화, GMO, 대체 에너지, 줄기세포 연구 등
직면한 문제
에너지 — 화석 연료 고갈, 소비 증가, 원자력 폐기물, 신재생 에너지의 낮은 효율 / 기후 — 온실 기체 배출 → 지구 온난화 → 기후 변화·사막화 / 오염 — 지구의 자정 능력 범위를 벗어난 배출
오개념
  • “지속가능한 삶 = 무조건 아껴 쓰기” → 현재의 필요와 미래의 가능성 사이의 균형 개념
  • 이산화 탄소를 대기 오염 물질로 혼동 → 이산화 탄소는 온실 기체
  • “오존층 파괴 = 지구 온난화” → 원인 물질과 기작이 다른 별개 현상
  • “모든 과학적 사실이 쟁점” → SSI는 가치 판단·이해관계가 개입될 때 성립
7차시 · 지속가능한 삶을 위한 과학기술과 실천
성취기준
[9과01-03] · 교과서 26~27쪽
해결 사례
플라스틱 — 미생물이 배설한 물질로 새 플라스틱 제조 / 에너지 — 수소·태양광 / 오염 — 오염 물질 회수 로봇 / 기후 — 이산화 탄소 포집·저장(CCS)
실천의 층위
  • 개인적 — 일회용품 줄이기, 자원 순환, 자전거·대중교통, 분리배출, 텀블러
  • 사회적 — 캠페인, 기업의 과대 포장 줄이기, 환경 부담금 부과, 배출 규제 국제 협약
핵심 관점
에너지·환경 문제의 발생 원인에 과학기술의 발전이 있지만, 해결하는 데에도 과학기술이 중요하게 작용한다. 이 양면성이 단원 전체의 결론이다.
오개념
  • 개인적/사회적 실천 혼동 → “주체가 개인인가, 제도·집단인가”로 판별. ‘환경 부담금 부과’는 사회 차원
  • “기술만 발전하면 해결” 또는 “개인 실천만으로 충분” → 두 축이 함께 필요
  • 재활용과 자원 순환 혼동 → 자원 순환은 사용량 감축 + 재활용을 포함하는 상위 개념
활동 운영
실천 인증 사진은 얼굴·개인정보가 드러나지 않게 안내. 댓글은 실천에 대한 의견만, 비난 금지. 수행 기간을 정해 두고 진행.
대단원 마무리 · 오개념 총정리
구성
생각 그물 쓱쓱 · 실력 향상 쑥쑥 · 디지털 소양 팡팡 · [인공지능] 과학 글쓰기(자율)
탐구
가설은 맞아야 한다 / 주관적 표현도 가설이 된다 / 조작변인 복수 설정 / 준비물만 같으면 변인 통제 완료
문명
과학 = 기술 = 공학 혼동 / 과학 발전은 항상 이롭다
지속
이산화 탄소 = 대기 오염 물질 / 오존층 파괴 = 지구 온난화 / 모든 과학적 사실이 쟁점 / 개인적·사회적 실천 혼동
서술형
과학기술의 양면성을 사례와 함께 진술할 수 있는지를 본다.

이 요약은 지도서와 교수·학습 지도안을 정리한 수업 보조 자료입니다. 평가 문항의 최종 확정과 성취기준 대비 타당도 검토는 교사의 전문적 검토를 거쳐 주십시오.
