# Ⅱ. 생물의 구성과 다양성 · 1. 생물의 구성 — 온라인 활동지 (`saengmul/`)

중학교 과학 1 · 2022 개정 교육과정. `taeyang/`, `jisok/`과 **같은 구조·같은 `quiz.js`·같은 Apps Script**를 사용합니다.

## 파일 구성

| 파일 | 용도 |
|---|---|
| `index.html` | 차시 목록 |
| `bio1.html` ~ `bio6.html` | 1~5차시 + 중단원 마무리 |
| `summary.html` | 차시별 요약 정리 (핵심 개념·오개념·안전·출제 포인트) |
| `view.html` | 내가 쓴 것 보기 (이 기기에 저장된 답안 조회) |
| `assets/questions.js` | 문항 정의 (정답 없음) |
| `assets/quiz.js` | taeyang의 파일을 **수정 없이 그대로** 복사 |
| `assets/keep.js` | 임시 저장 · 제출 내용 보관 |
| `assets/config.js` | Apps Script URL — **taeyang의 것으로 덮어쓸 것** |
| `assets/style.css` | 공통 스타일 |
| `정답표_교사용.md` | 정답 시트 입력용 — **저장소에 올리지 말 것** |

## 차시 대응

| ID | 차시 | 소단원 | 교과서 | 문항 수 |
|---|---|---|---|---|
| `bio1` | 1/6 | 01 세포(1) | 31~35쪽 | 10 (서술 1) |
| `bio2` | 2/6 | 01 세포(2) 탐구 | 36~37쪽 | 9 (서술 2) |
| `bio3` | 3/6 | 01 세포(3) | 38~39쪽 | 10 (서술 2) |
| `bio4` | 4/6 | 01 세포(4) 해 보기 | 40~41쪽 | 8 (서술 2) |
| `bio5` | 5/6 | 02 생물의 구성 단계 | 42~44쪽 | 10 (서술 1) |
| `bio6` | 마무리 | 중단원 종합 | 31~44쪽 | 13 (서술 1) |

> 제공된 지도안에는 **6/6차시 분량이 포함되어 있지 않습니다.** `bio6`은 중단원 마무리 종합 정리로 구성했습니다. 6차시 지도안을 주시면 그에 맞게 교체해 드립니다.

## 배포

```bash
# ms1 저장소 루트에서
cp -r <다운로드>/saengmul ./
rm saengmul/정답표_교사용.md
cp taeyang/assets/config.js saengmul/assets/config.js
cp taeyang/answers.html taeyang/teacher.html saengmul/     # 차시 ID를 bio1~bio6으로 수정
git add saengmul && git commit -m "Add unit II-1 worksheets" && git push
```

접속 주소: `https://polarbears78.github.io/ms1/saengmul/`

## 스프레드시트 준비 (배포 전 필수)

1. **정답 시트**에 `정답표_교사용.md`의 내용을 `bio1`~`bio6` ID로 추가 (선택형 저장값은 0부터)
2. **공개 상태 시트**에 `bio1`~`bio6` 행 추가, 초기값 `N`
3. `teacher.html`에서 6개 차시가 모두 보이면 정상

> **ID 주의** — `ws1~ws5`(태양계), `sus1~sus8`(Ⅰ단원)과 겹치면 제출 기록과 정답이 섞입니다.

## 2차시(실험) 운영 유의

- 덮개 유리 파손 주의, **깨진 유리는 맨손으로 줍지 않게** 사전 지도
- 염색액 사용 시 환기. 아세트올세인·아세트산 카민 사용 시 특히 유의
- 면봉은 1인 1개, 사용 후 지정 용기에 폐기
- 활동지 제출보다 **관찰 태도와 안전 수칙 준수의 현장 관찰 기록**이 우선입니다
