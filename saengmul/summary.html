← 차시 목록 Ⅱ-1. 생물의 구성

차시별 요약 정리

핵심 개념 · 자주 나오는 오개념 · 실험 안전 · 출제 포인트

중단원 관통 논지 — 세포는 생명활동의 기본 단위이고, 세포의 구조는 그 세포가 하는 일에 맞게 갖추어져 있으며, 세포가 모여 단계적으로 하나의 개체를 이룬다. 3~4차시(구조·기능)와 5차시(구성 단계)가 이 논지로 연결됩니다.

1차시 · 세포의 발견과 세포
학습 목표
세포는 생명활동이 일어나는 기본 단위임을 설명할 수 있다.
교과서
31~35쪽 · 준비물: 교과서, 개념 정리 활동지 · 도입 10 / 전개 20 / 정리 15분
핵심 개념
  • 세포의 발견 — 훅이 코르크를 관찰해 벌집 모양의 작은 방을 발견하고 ‘세포’라 이름 붙임
  • 세포 — 생명활동이 일어나는 생물의 기본 단위
  • 단세포 생물 — 아메바, 짚신벌레, 세균 / 다세포 생물 — 사람, 개구리, 소나무
  • 현미경 — 접안렌즈, 대물렌즈, 재물대, 조동나사, 미동나사, 조리개 / 배율 = 접안렌즈 × 대물렌즈
오개념
  • “배율을 높이면 더 밝고 넓게 보인다” → 배율이 높아지면 시야는 좁아지고 어두워진다. 저배율에서 시작해야 하는 이유가 여기에 있다.
  • “훅이 살아 있는 세포를 보았다” → 훅이 본 것은 죽은 코르크의 세포벽이 남긴 빈 공간이다.
  • “단세포 생물은 세포 하나라 단순하다” → 하나의 세포가 모든 생명활동을 스스로 수행한다.
출제 포인트
단세포/다세포 예시 분류, 배율 계산, 현미경 조작 순서, 저배율 우선의 까닭 서술
수업 팁
현미경의 역사 관련 영상을 함께 보면 도입 동기가 살아납니다.
2차시 · 현미경으로 세포 관찰하기 [탐구]
학습 목표
현미경으로 세포를 관찰하고 세포의 특징을 설명할 수 있다.
교과서
36~37쪽 · 도입 5 / 전개 35 / 정리 5분
준비물
스마트 기기, 신경세포·적혈구 영구표본, 검정말, 메틸렌 블루 용액, 물, 핀셋, 받침 유리, 덮개 유리, 스포이트, 거름종이, 페트리 접시, 면봉, 광학 현미경, 실험용 장갑, 실험복
탐구 순서
재료 올리기 → 물 한 방울 → 덮개 유리를 비스듬히 천천히 덮기(공기 방울 방지) → 한쪽에 염색액, 반대쪽에서 거름종이로 빨아들이기 → 저배율 관찰 후 고배율
비교 관찰
검정말 잎 — 세포벽·엽록체 뚜렷 / 입안 상피세포 — 세포벽·엽록체 없음, 염색해야 핵이 보임 / 적혈구 — 가운데가 오목한 원반 / 신경세포 — 가늘고 길게 뻗음
안전 관리
  • 덮개 유리가 깨져 손이 베이지 않도록 조심하고, 깨진 유리는 맨손으로 줍지 않는다
  • 염색액 사용 시 환기. 아세트올세인·아세트산 카민 사용 시 특히 유의
  • 실험용 장갑과 실험복 착용, 면봉은 1인 1개 사용 후 지정 용기에 폐기
오차·실패 요인
공기 방울을 세포로 오인(테두리가 검고 두껍게 보임) / 염색액 과다로 시야가 어두움 / 검정말을 너무 두껍게 놓아 초점이 맞지 않음 / 조리개를 너무 열어 상이 흐림
오개념
“공기 방울도 세포다” → 경계선의 굵기와 규칙성으로 구분하게 한다. “염색하면 세포가 죽어서 못 본다” → 관찰용 표본은 애초에 살아 있는 상태의 유지가 목적이 아니다.
3차시 · 세포의 구조와 기능
학습 목표
세포벽, 세포막, 핵, 엽록체, 마이토콘드리아의 기능을 설명할 수 있다.
교과서
38~39쪽 · 도입 10 / 전개 30 / 정리 5분
세포소기관
  • 핵 — 유전물질이 들어 있어 생명활동을 조절
  • 세포막 — 물질의 출입을 조절
  • 세포벽 — 식물 세포에만. 모양 유지와 보호
  • 엽록체 — 광합성으로 양분을 만듦
  • 마이토콘드리아 — 세포 호흡으로 에너지를 얻음
비유 활동
세포를 사탕 공장에 비유 — 담장(세포벽), 출입문(세포막), 공장장실(핵), 발전실(마이토콘드리아), 생산 공정(엽록체)
지도 유의점
비유는 흥미와 이해를 돕지만 지나친 확대 해석은 오개념을 만듭니다. 세포소기관은 비유물보다 훨씬 역동적이고 여러 기능을 가진다는 점을 반드시 짚어 주십시오. 원핵생물을 배우지 않은 단계이므로 유전물질은 핵을 통해 설명합니다.
오개념
  • “식물 세포에는 마이토콘드리아가 없다” → 식물도 세포 호흡을 하므로 있다. 광합성과 호흡을 대립 관계로 보는 오개념과 함께 나타난다.
  • “세포벽 = 세포막” → 세포벽은 식물에만 있고 물질 출입을 조절하지 않는다.
  • “핵이 없으면 세포가 아니다” → 이 단계에서는 다루지 않으나, 단정적 진술은 피한다.
출제 포인트
식물/동물 세포 비교표 완성, 기능→소기관 역추론, 비유의 한계 서술
4차시 · 세포의 구조와 기능의 관계 [해 보기]
학습 목표
세포의 구조와 기능의 관계를 추론할 수 있다.
교과서
40~41쪽 · 도입 5 / 전개 35 / 정리 5분
사례
  • 신경세포 — 가늘고 길게 뻗음 → 자극을 먼 곳까지 빠르게 전달
  • 적혈구 — 가운데가 오목한 원반 → 표면적이 넓고 좁은 혈관 통과에 유리
  • 뿌리털 — 돌기 모양 → 표면적을 넓혀 물과 무기 양분 흡수
  • 정자 — 긴 꼬리 → 스스로 이동
  • 물관 — 세포가 위아래로 이어지고 세포벽 일부가 없어져 긴 관 → 물의 이동 통로
사고 방향
“이 세포는 무슨 일을 하는가” → “그 일에 유리한 모양은 무엇인가” 순으로 기능에서 구조를 추론하게 합니다. 더 추론해 보기(물관)는 창발적 사고를 기르는 활동입니다.
오개념
  • “세포가 필요해서 모양을 바꾸었다” → 목적론적 진술. “그 모양이 그 일에 유리하다”로 고쳐 진술하게 한다.
  • “모든 세포는 둥글다” → 교과서 모식도의 인상에서 오는 오개념.
평가 요소
기능과 구조를 인과로 연결해 진술했는가 / 근거 없이 외운 내용을 나열하지 않았는가
5차시 · 생물의 구성 단계 [해 보기]
학습 목표
생물의 유기적 구성 단계를 이해하고, 식물과 동물의 구성 단계를 비교해 설명할 수 있다.
교과서
42~44쪽 · 도입 5 / 전개 35 / 정리 5분
구성 단계
  • 동물 — 세포 → 조직 → 기관 → 기관계 → 개체
  • 식물 — 세포 → 조직 → 조직계 → 기관 → 개체
용어
조직(모양·기능이 비슷한 세포의 모임) · 기관(여러 조직이 모여 일정한 기능) · 기관계(소화계·순환계·호흡계·배설계 등) · 조직계(표피조직계·관다발조직계·기본조직계)
오개념
  • 조직계와 기관계를 바꿔 쓰는 것 → 가장 잦은 실수. “조직계는 식물, 기관계는 동물”로 위치가 다르다는 점까지 함께 외우게 한다.
  • “식물에는 기관이 없다” → 뿌리·줄기·잎·꽃이 기관이다.
  • “단계가 올라갈수록 세포가 커진다” → 세포의 수와 조직화 수준이 달라지는 것이다.
출제 포인트
순서 배열, 식물/동물 단계의 차이 서술, 제시된 사례(위·잎·소화계 등)를 알맞은 단계로 분류
중단원 마무리 · 오개념 총정리
세포
배율↑ = 시야 넓고 밝다(×) / 훅이 살아 있는 세포를 관찰(×) / 공기 방울을 세포로 오인
구조
식물 세포에 마이토콘드리아 없음(×) / 세포벽 = 세포막(×) / 비유물과 세포를 동일시
기능
세포가 필요해서 모양을 바꾸었다는 목적론적 진술 / 모든 세포는 둥글다
구성 단계
조직계(식물) ↔ 기관계(동물) 혼동 / 식물에는 기관이 없다(×)
서술형
세포 → 개체까지의 단계를 사례와 함께 진술할 수 있는지를 본다.
